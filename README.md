# Easy Differ

一个基于 Monaco Editor 的在线文本差异对比工具。

## 功能

- **并排对比**：左右双栏实时显示文本差异
- **字符级高亮**：新增字符绿色高亮，删除字符红色高亮
- **多语言支持**：纯文本、JavaScript、HTML、CSS、JSON、Java
- **一键清空**：快速清除两侧编辑器内容
- **纯前端**：无需后端服务，打开即用

## 使用

直接在浏览器中打开 `index.html` 即可使用。

- 左侧粘贴**基准**文本，右侧粘贴**对比**文本
- 通过顶部下拉框切换语法高亮语言
- 点击「清空内容」按钮重置编辑器

## 技术

- [Monaco Editor](https://microsoft.github.io/monaco-editor/) v0.45.0（CDN 加载）
- 自定义暗色主题，取消整行背景色，仅高亮变动字符
