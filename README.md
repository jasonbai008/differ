# Easy Differ

一个基于 Monaco Editor 的在线文本差异对比工具。

## 功能

- **并排对比**：左右双栏实时显示文本差异，支持拖动调整左右视图宽度
- **字符级高亮**：新增字符绿色高亮，删除字符红色高亮
- **多语言支持**：纯文本、HTML、CSS、JSON、JavaScript、TypeScript、Markdown、Python、Java
- **空行处理**：支持清除左侧或右侧空行，也支持一键清空全部内容
- **移动端适配**：响应式设计，自动适配移动设备屏幕
- **纯前端**：无需后端服务，打开即用

## 使用

直接在浏览器中打开 `index.html` 即可使用。

- 左侧粘贴**基准**文本，右侧粘贴**对比**文本
- 通过顶部下拉框切换语法高亮语言
- 点击「清除左侧空行」按钮移除左侧空白行
- 点击「清除右侧空行」按钮移除右侧空白行
- 点击「清空内容」按钮重置两侧编辑器

## 技术

- [Monaco Editor](https://microsoft.github.io/monaco-editor/) v0.43.0（CDN 加载）
- 自定义暗色主题，取消整行背景色，仅高亮变动字符
- 响应式设计，移动端自动隐藏标签文字并调整布局
